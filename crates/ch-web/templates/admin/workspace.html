Code editor in the browser

People who can read a repository can open it in an editor at its Workspace link. People who can write can commit from there. Everyone must be signed in.

Terminal in the browser

People who can read a repository can open a shell in their own browser, on a copy of its files. It runs only in their browser, has no internet, and never runs on this server. Everyone must be signed in.

{% if !allowed %}

The server's config file turns the workspace off ([workspace] enabled = false). Change it there first.

{% else if !terminal_allowed %}

The server's config file turns the terminal off ([workspace] terminal = false). Change it there first.

{% else if !editor %}

Turn the editor on first. The terminal lives inside it.

{% else if terminal %}

The terminal is on.

{% call ui::csrf_field(c.csrf) %}
{% else %}

The terminal is off.

{% call ui::csrf_field(c.csrf) %}
{% endif %}
